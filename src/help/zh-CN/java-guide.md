# Java 配置与选择

Minecraft 运行于 Java 虚拟机之上。不同游戏版本对 Java 的主版本有严格的要求，正确的 Java 配置是稳定运行的基础。

## 版本对应关系推荐

- **Minecraft 1.20.5 及更高版本**：需要 **Java 21**。
- **Minecraft 1.18 - 1.20.4**：需要 **Java 17**。
- **Minecraft 1.17**：需要 **Java 16**。
- **Minecraft 1.16.5 及更低版本（包括 1.12.2、1.7.10）**：建议使用 **Java 8**。

## 启动器内置自动匹配

MCLR 默认开启了 **自动 Java 推荐**：
- 启动器会在本地系统的注册表、`Program Files`、环境变量以及安装目录中扫描所有可用的 Java 运行环境。
- 启动游戏时，MCLR 会根据该游戏版本的规则自动匹配最兼容且性能最优的 Java。
- 如果系统中缺少对应版本的 Java，启动器会提示并允许你一键下载官方或镜像维护的兼容运行环境。

## 游戏内存分配建议

- **原版纯净客户端**：推荐分配 `2048 MB` ~ `4096 MB`。
- **小型/轻量模组整合包（< 80 个模组）**：推荐分配 `4096 MB` ~ `6144 MB`。
- **大型工业/魔法/冒险整合包（200+ 模组）**：推荐分配 `8192 MB` ~ `10240 MB`。
- **注意**：切勿将物理机所有内存全部借给游戏，通常应至少为操作系统保留 `2 GB` 以上空闲内存。
