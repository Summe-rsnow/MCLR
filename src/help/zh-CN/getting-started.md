# 新手起步指南

欢迎使用 MCLR（Minecraft Launcher Rewrite）！本指南将带你从零开始快速安装并畅玩 Minecraft。

## 第一步：添加游戏账号

在启动游戏前，你需要至少配置一个账号：
1. 点击左侧导航栏的 **账号管理**。
2. 点击右上角 **添加账号**。
3. 选择你的账号类型：
   - **微软账号**：拥有正版 Minecraft 的玩家推荐使用，支持安全设备码快速登录。
   - **第三方验证**：支持第三方皮肤站与认证服务（如 LittleSkin、统一通行证等）。
   - **离线账号**：无需联网验证，输入任意玩家名即可体验。

## 第二步：安装 Minecraft 核心版本

1. 点击左侧导航栏的 **下载中心**。
2. 在 **原版核心** 列表中浏览或搜索你想要游玩的版本（如 `1.21.4`、`1.20.1`）。
3. 输入实例名称（例如 `My1.21`），点击 **安装**。
4. 安装任务会自动在后台运行，包括核心 Jar、依赖库以及游戏原版资源包。你可以在顶部状态栏查看下载进度。

## 第三步：一键启动游戏

1. 点击左侧导航栏的 **启动主页**。
2. 确认选中的游戏实例以及当前玩家账号。
3. 点击醒目的 **启动游戏** 按钮！
4. 启动器将自动完成 Java 匹配与环境校验，并在几秒钟内唤起游戏窗口。
