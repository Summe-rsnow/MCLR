# 游戏崩溃与排查分析

游戏意外退出或者提示非 0 退出代码？不要慌张，MCLR 内置了专业的崩溃诊断与分析引擎。

## 常见崩溃原因速查

1. **Java 主版本不匹配**
   - 现象：启动瞬间闪退或日志出现 `UnsupportedClassVersionError`。
   - 解决：前往实例设置，为该实例指定匹配的 Java 版本（如 1.20+ 使用 Java 17/21）。

2. **缺少必要的前置模组（Dependency Missing）**
   - 现象：加载阶段弹出错误，提示需要特定 Mod ID 及其最小版本。
   - 解决：进入 **实例管理** -> **模组** 标签页，查看缺失依赖并点击自动下载前置模组。

3. **模组冲突（Mod Incompatibility）**
   - 现象：混合安装了相同功能的底层重构模组或不兼容版本的模组。
   - 解决：关闭最近新加的模组，或使用二分法逐批排查。

4. **内存不足（OutOfMemoryError）**
   - 现象：加载大型模组整合包在载入纹理阶段直接闪退。
   - 解决：调高最大分配内存（例如从 4096 MB 提升至 8192 MB）。

## 使用 MCLR 崩溃诊断

- 当游戏异常退出时，MCLR 会自动弹出 **崩溃分析报告窗口**。
- 分析引擎会智能提取 `crash-reports` 与 `latest.log`，通过 40+ 条排查规则直接定位疑似冲突模组。
- 你可以点击 **一键导出崩溃报告包**（包含日志、运行参数与系统环境），方便分享给社区或朋友协助排查。
