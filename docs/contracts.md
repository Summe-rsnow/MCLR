# Cross-Cutting Contracts

1. **Paths** (`mclr_core::paths`): `data_dir() = %APPDATA%/MCLR`; children `config.json`, `accounts.enc`, `master.key`, `cache/`, `logs/`, `runtime/` (downloaded Java), `tools/` (authlib-injector.jar), `.minecraft/` (default game folder). Override root with env `MCLR_DATA_DIR` (used by tests and smoke runs).
2. **Settings** (`mclr_core::settings`): one `Settings` struct, `#[serde(rename_all="camelCase", default)]`, field `schemaVersion: u32 = 1`; atomic write (tmp + rename), debounced 300 ms save. IPC: `settings_get() -> Settings`, `settings_patch(patch: serde_json::Value)` (RFC 7386 merge patch, validated by deserialising into `Settings`, rejects with `AppError{code:"settings.invalid"}`), event `settings://changed`. Each milestone adds its own sub-struct (`launch`, `java`, `net`, `ui`, `update`, `language`, …) in its own file under `mclr-core/src/settings/` and registers it in `settings/mod.rs` (append-only).
3. **Errors**: each crate has a `thiserror` enum implementing `fn code(&self)->&'static str` (`<crate>.<kind>`, e.g. `net.timeout`, `auth.xsts.noXboxAccount`) and `Into<AppError>`. Tauri commands return `Result<T, AppError>`.
4. **Tasks** (`mclr_core::tasks`): `TaskCenter` holds a tree of tasks `{id, parentId, titleKey, titleParams, state: waiting|running|success|canceled|failed, progress: 0..1, speedBps, error?: AppError}` with `pause/resume/cancel` via `CancellationToken`. Events on Tauri channel `tasks://update` (diff payload). IPC: `tasks_list`, `task_cancel(id)`, `task_pause(id)`, `task_resume(id)`. Every long operation (install, download, modpack, java download, update) runs as a task; titles are i18n keys under `task.*`.
5. **IPC naming**: commands `<feature>_<verb>` snake_case; payloads camelCase; events `<feature>://<name>`. Command registry is one `tauri_specta::collect_commands![...]` in `src-tauri/src/commands.rs`, split in marked blocks `// [feature]` — a sub-agent only appends inside its own block (re-read the file before editing).
6. **Frontend extension points** (so sub-agents never collide): routes from `import.meta.glob('./features/*/routes.ts')`; nav items declared in each `routes.ts` (`meta.nav = {titleKey, icon, order}`); locale files per feature; stores per feature; mocks per feature registered by glob in `src/ipc/mock.ts`.
7. **Tests**: offline by default (fixtures in `crates/<c>/tests/fixtures`, `wiremock` for HTTP). Real-network tests are `#[ignore]`d and run only in milestone smoke via `cargo test -p <crate> -- --ignored`.
8. **Check gate** `pnpm check` = `cargo fmt --all --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo test --workspace` → `pnpm gen:bindings && git diff --exit-code src/ipc/bindings.ts` (skipped before first commit) → `vue-tsc --noEmit` → `vitest run` → `node scripts/lint-i18n.mjs` → `vite build`. `lint-i18n.mjs` fails on: CJK characters in `src/**/*.{vue,ts}` outside `src/locales/`, `*.test.ts`, `mock.ts`; any static `t('…')`/`$t('…')`/`keypath="…"` whose key is missing from `zh-CN`.
